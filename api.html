API 文档

绿角犀官网后台与公开接口一览。所有接口基于 JSON，base URL 即站点根域名。

约定

  • 基础地址：https://<你的域名>（本地开发为 http://localhost:3000）。
  • 请求与响应体均为 application/json（埋点接口除外，仅返回状态）。
  • 后台接口需在请求头携带 Authorization: Bearer <token>；admin 角色才可执行写操作，viewer 仅可读。
  • 失败统一返回 { "error": "...", "requestId": "..." }，便于排障。

公共接口（无需登录）

面向前端展示与埋点，可被匿名调用（部分带限流）。
GET
/api/health
轻量健康检查，返回 status / uptime / time / db。不暴露 Node 版本。
公开
GET
/api/health/detail
深度检查：数据库、备份、备份校验、磁盘、内存、日志；异常返回 503。需登录。
需 Token
GET
/api/products?type=app|game&category=分类
已上架产品列表；可按类型 / 分类筛选，返回 category、sort、image（产品大图，空=卡片回退 emoji 图标）字段。按排序权重 sort 降序排列（权重越大越靠前，实现产品置顶），同权重回退到 ID 升序。
公开
GET
/api/products/hot?limit=N
热门下载排行：仅已上架产品，按下载量降序返回 TOP N（limit 1~10 钳制，缺省 5）。条目含完整产品字段 + downloads 计数。下载量已按同 IP 24h 窗口去重。
公开
GET
/api/products/:id
单个产品详情（含下载量、分类、截图等）。
公开
GET
/api/products/:id/related?limit=N
相关推荐：同分类优先 → 同类型补充 → 其余兜底，均排除当前产品，按下载量/排序权重/ID 综合排序。limit 1~8 钳制（缺省 4）；产品不存在 404、非法 id 400。
公开
GET
/api/categories
产品分类枚举（后台可维护）：返回 [{id, name}]，下载页分类区据此自动生成。
公开
GET
/api/announcement
前台公告条：返回最新一条启用中的公告 {id, content, created_at, updated_at}；无公告返回 null。
公开
POST
/api/views
浏览量埋点。限流 60 次/分钟。Body：{ "page": "/", "referer": "", "ua": "…", "lang": "…", "tz": "…" }（ua/lang/tz 用于后台「访问分析」的浏览器/系统/语言/时区分布，可缺省）。
公开 · 限流
POST
/api/downloads
下载量埋点。限流 30 次/分钟。Body：{ "productId": 1 }
公开 · 限流
POST
/api/contact
提交留言/联系表单。限流 30 次/10 分钟；含蜜罐字段防滥用。Body：{ "name", "email", "message", "website"(蜜罐留空) }
公开 · 限流
POST
/api/feedback
提交产品反馈。限流 5 次/10 分钟（按 IP）；仅允许反馈上架中的产品（否则 404）。Body：{ "productId", "name", "email", "content", "rating"(0~5 可缺省), "company"(蜜罐留空) }。内容 1~500 字、邮箱（可选）须合法；蜜罐命中 / 校验失败返回 400。返回 { ok:true, id }。
公开 · 限流
GET
/api/products/:id/feedback?limit=N
前台评分聚合（详情页评价区）：仅统计后台已审核（status=done）的反馈，返回 { count, ratedCount, avg, rows }——count 总条数（含无评分）、ratedCount 有评分条数、avg 平均分（保留 1 位小数，无评分 0）、rows 最新评价摘要（时间倒序，limit 1~20 钳制缺省 5）。未审核反馈前台不可见；产品不存在 404、非法 id 400。
公开

后台接口（Bearer Token）

登录后所有请求携带 Authorization: Bearer <token>。写操作需 admin 角色。
POST
/api/admin/login
登录获取 Token。Body：{ "username", "password" }。返回 { token, expiresAt, role, username }。
公开
PUT
/api/admin/password
修改当前账号口令（旧口令校验）。写入后立即使旧 Token 失效。
admin
GET
/api/admin/admins
列出管理员账号（id / username / role / created_at）。
admin
POST
/api/admin/admins
新建管理员。Body：{ "username", "password", "role": "admin|viewer" }。
admin
PUT
/api/admin/admins/:id
修改管理员角色。Body：{ "role": "admin|viewer" }。最后一个 admin 不可降级为 viewer（防止后台锁死）。
admin
DELETE
/api/admin/admins/:id
删除管理员账号。不可删除当前登录账号；最后一个 admin 不可删除（防止后台锁死）。
admin
GET
/api/admin/backup
触发一次数据库备份并即时校验完整性。
admin
GET
/api/admin/stats
数据看板：浏览/下载趋势、未处理留言数、产品上下架统计、访问分析分布（browsers/oses/langs/timezones）与反馈概览（feedback: {total, pending, ratedCount, avg, byProduct, week[7]}：总数/未处理/有评分数/平均分/按产品分布 TOP5/近 7 天趋势）。
需 Token
GET
/api/admin/stats/trend?days=7|14|30
流量趋势：按天返回浏览/下载量 + 区间合计。days 钳制 1~90（默认 14）。
需 Token
GET
/api/admin/sysinfo
系统信息：备份状态、磁盘占用、是否为默认口令等。
需 Token
GET
/api/admin/audit?page=1&pageSize=10&keyword=&action=login
操作审计日志：服务端分页（page/pageSize，上限 100）+ 关键词（操作/详情/IP 模糊）+ 操作类型筛选，返回 { rows, total }。
需 Token
GET
/api/admin/accesslog
最近 100 条访问日志（含轮转备份）。
需 Token
GET
/api/admin/products
后台产品列表（含下架项与下载量）。
需 Token
POST
/api/admin/products
新建产品。Body 含 title, type, category, desc, downloadUrl, visible 等，sort（整数，-9999~9999）为排序权重，越大越靠前；image 为产品大图（http(s) 链接或站内 /assets/img/… 路径，空=回退 emoji，拒绝 javascript:/data: 等危险协议）。
admin
POST
/api/admin/products/import
CSV 批量导入产品（admin）。Body：{ "csv": "名称,类型,分类,…\n…" }。RFC4180 解析（引号包裹/转义/CRLF/自动去 BOM），表头支持中英文别名（如 名称/name、下载链接/download_url），类型列可写 应用/游戏 或 app/game。逐行校验（与手动上架同规则），任一行非法则整批 400 拒绝并返回 {ok:false,total,failed:[{line,error}]}（line 为 CSV 行号）；全部合法则事务写入并返回 {ok:true,imported,total,ids}。单次 ≤100 行，写审计。
admin
POST
/api/admin/products/bulk/status
批量上架 / 下架（admin）。Body：{ "ids": [1,2,3], "status": "on|off" }。ids 须为 1~500 个正整数（空 / 超长 / 含非法值 → 400）；返回 { ok:true, changed:N }，写审计。
admin
POST
/api/admin/products/bulk/category
批量修改分类（admin）。Body：{ "ids": [1,2], "category": "工具" }。category 必须为后台维护的枚举分类（空串 = 清空分类；非法字符 / 非枚举项 → 400）；返回 { ok:true, changed:N }，写审计。
admin
POST
/api/admin/products/bulk/delete
批量删除产品（admin）。Body：{ "ids": [1,2] }（ids 校验同上）；返回 { ok:true, changed:N }，写审计。
admin
PUT
/api/admin/products/:id
更新产品信息。
admin
DELETE
/api/admin/products/:id
下架并删除产品。
admin
POST
/api/admin/upload
产品图片直传（admin）。Body：{ "data": "data:image/png;base64,…" }。仅接受 PNG / JPG / WebP / GIF（魔数嗅探校验内容，拒绝伪装文件），单图 ≤2MB；成功落盘 assets/img/products/ 并返回 { ok:true, url:"/assets/img/products/…" }，可直接填回产品的 image 字段。
admin
GET
/api/admin/categories
产品分类列表（含各分类使用产品数 usage，供删除保护参考），返回 {rows:[{id,name,created_at,usage}]}。
需 Token
POST
/api/admin/categories
新增分类 { "name": "效率" }；名称重复返回 409，字符/长度非法返回 400。
admin
PUT
/api/admin/categories/:id
重命名分类（同步更新引用该分类的所有产品，保持数据一致）。
admin
DELETE
/api/admin/categories/:id
删除分类；该分类下有产品使用时返回 409（防孤儿引用），产品表单与下载页分类区将随之变化。
admin
GET
/api/admin/announcements
公告列表（含停用项），按 id 倒序，返回 {rows:[{id,content,enabled,created_at,updated_at}]}。
需 Token
POST
/api/admin/announcements
发布公告。Body：{ "content": "…", "enabled": 1 }（enabled 可省，默认 1）。内容非空且 ≤200 字符，写审计；发布后最新一条启用中的公告立即在前台公告条展示。
admin
PUT
/api/admin/announcements/:id
编辑公告内容 / 启停。Body：{ "content": "…", "enabled": 0|1 }。停用后前台自动回退到上一条启用公告。
admin
DELETE
/api/admin/announcements/:id
删除公告，写审计。
admin
GET
/api/admin/maintenance
读取站点维护模式状态，返回 { enabled: 0|1, message: "…" }。
admin
PUT
/api/admin/maintenance
开启 / 关闭站点维护模式（admin）。Body：{ "enabled": 1, "message": "站点升级中…" }。message 维护提示语 ≤200 字符（可省，前台维护页展示）。开启后前台 HTML 与公开业务 API 统一返回 503（后台页 / 后台接口 / 静态资源 / /api/health* / /api/site 保持可用，管理员可随时关闭）；写审计 maintenance_on/off。

PUT

数据模型速览

便于对接前端与第三方系统。

Product（产品）

id, title, type(app|game), category, desc, icon, screenshots[], downloadUrl, version, size, visible(bool), views, downloads, createdAt, updatedAt

Contact（留言）

id, name, email, message, status(pending|done|ignored), ip, createdAt

Admin（管理员）

id, username, role(admin|viewer), createdAt —— 口令以 scrypt + 独立盐存储，不暴露明文

Feedback（产品反馈）

id, product_id(联表 product_name), name, email, content, rating(0~5), status(new|done), ip, createdAt

完整实现以 server/routes.js 为准。后台入口：admin.html
