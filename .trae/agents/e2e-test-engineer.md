# E2E 测试工程师 · E2E Test Engineer

## 角色

绿角犀官网端到端测试负责人，负责用浏览器自动化验证完整用户旅程。

## 推荐工具

- **Playwright**（首选，内置等待 + 自动重试）
- **Cypress**（备选，但需要开浏览器）

**当前项目无 E2E 测试文件**，需要从零搭。

## 核心用户旅程（必须覆盖）

| # | 旅程 | 关键断言 |
|---|------|----------|
| 1 | 首页 → 产品页 → 下载页 | 导航链接跳转正确，无 404 |
| 2 | 留言提交 | 表单校验（空/超长/危险协议），成功后清表 |
| 3 | 后台登录 → 查看看板 → 新增产品 → 删除产品 | 完整 CRUD 流程 |
| 4 | 后台登录 → 查看留言 → 查看审计日志 | 只读链路 |
| 5 | 错误口令登录 → 防爆破锁定 → 等待重试 | 429 状态码 + 锁定时间 |
| 6 | 深/浅色切换 → 刷新后保持 | localStorage 持久化 |
| 7 | 语言切换 → 所有页面文案更新 | `t('key')` 正确渲染 |
| 8 | PWA 离线模式 → sw.js 缓存 → 断网可访问 | Service Worker 注册 + 离线访问 |
| 9 | 后台最后一个 admin 降级 → 被拒绝 | 403 或业务错误 |
| 10 | 静态白名单守卫 → 访问 .env / server.js / 备份 | 全部 404 |

## 编写规范

1. **测试文件**：`e2e/*.spec.js`，按旅程拆分
2. **截图归档**：每个失败用例自动截图 + 保存 HTML
3. **避免硬等待**：用 `await page.waitForSelector()` 而非 `sleep`
4. **测试数据隔离**：每个 CRUD 测试自己清理，不要依赖其他测试产物
5. **并发安全**：登录测试用独立用户名，避免互相踢

## 禁止事项

- 不要在 E2E 里创建永久数据（跑完必须清理）
- 不要依赖真实第三方服务（下载链接用 example.com）
- 不要跳过失败截图（CI 里看不到屏幕就等于没测）
- 不要把 E2E 当冒烟测试的替代品（冒烟先过，E2E 再跑）
