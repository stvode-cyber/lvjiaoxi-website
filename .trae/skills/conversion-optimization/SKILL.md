# 转化率优化（CRO）

## 触发条件
调整下载页、产品页、或用户说"让更多人下载/注册"时使用。

## 核心原则

**极简路线 = 转化漏斗越短越好。** 绿角犀不做复杂注册流程，但以下环节影响下载率：

```
首页 → 产品页 → 下载页 → 点击下载 → 安装完成 → 首次使用
  ↑         ↑         ↑         ↑
 触达     信任      行动     完成
```

## 优化清单

### 1. 下载页（最高优先级）

当前 download.html 功能完整，但可加：

| 优化项 | 做法 | 竞品参考 |
|--------|------|---------|
| **下载按钮 CTA 文案** | "立即免费下载" → "下载绿角犀 · 100% 免费 · 无捆绑" | 360 官网突出"官方正版" |
| **多平台图标** | Windows / macOS / Linux 图标并排，点击跳对应下载 | Brave 官网 |
| **版本号 + 更新日期** | "当前 v1.2.0 · 2026-09-10 更新"，加 changelog 链接 | Firefox 官网 |
| **下载计数** | 后台 `/api/products` 返回 `downloads` 字段，前端显示"已下载 10,000+" | 社会认同 |
| **安全徽章** | "数字签名 ✅" / "无广告 ✅" / "开源 ✅"（如果是） | 信任信号 |

### 2. 产品页

| 优化项 | 做法 |
|--------|------|
| **功能卡片加"为什么选绿角犀"** | 每个功能卡片底部加一行"比 XXX 更 XXX" |
| **截图 + 短视频** | 当前只有图片，可加 5 秒动图演示 |
| **定价策略** | "永久免费" 大字标（竞品多有免费版） |

### 3. 首页

| 优化项 | 做法 |
|--------|------|
| **首屏 CTA 唯一性** | 当前"了解更多"和"立即下载"两个按钮，移动端突出下载 |
| **信任信号前置** | 首屏下方加"XX 用户正在使用" / "国家信息安全认证" |
| **骨架屏** | 避免白屏时用户以为卡死 |

### 4. 后台引导

当前 admin.html 功能完整，但内测人员首次进入时可能懵：

| 优化项 | 做法 |
|--------|------|
| **首次登录引导** | 首次登录显示 3 步引导（添加产品 → 配下载地址 → 上线） |
| **空状态提示** | 产品列表空时显示"添加第一个产品"按钮 + 模板 |
| **统计概览卡** | 首页 stats 加"最近 7 天下载趋势"折线图 |

## 数据分析

后台 `/api/admin/stats` 返回的数据可以指导优化：

```js
// 当前 stats 结构
{
  totalProducts, totalContacts, pendingContacts,
  totalAdmins, todayContacts, weekContacts, version
}

// 建议新增（需要改后端）
{
  downloadTrend: [{ date, count }],    // 下载趋势
  trafficByPage: [{ page, hits }],     // 页面访问分布
  conversionBySource: [{ source, rate }], // 转化率
}
```

## 快速验证

```bash
# 用 curl 看各页面响应时间
curl -s -o /dev/null -w "%{time_total}s %{http_code} %{url_effective}\n" http://127.0.0.1:3002/{index,product,download}.html
# 3s 以上要优化
```

## A/B 测试建议（长期）

如果未来有流量，可以测：
- 下载按钮文案 A/B
- 信任信号位置 A/B
- 首屏 CTA 数量 A/B

但当前内测阶段**不要做**，先跑通再优化。

## 禁止事项

- 不要加弹窗广告/强制注册
- 不要加"限时免费"（绿角犀定位永久免费）
- 不要用假数据（下载计数/用户数）
- 不要引入埋点服务（保持极简）
