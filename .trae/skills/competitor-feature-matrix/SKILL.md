## 官网可落地的功能展示建议

### P1 — 低成本高价值（立即加）

1. **新增"安全特性"版块**
   - 在产品页增加安全特性可视化展示
   - DNS 加密 ✅ / 防追踪 ✅ / 安全沙箱 ✅
   - 用图标 + 一句话说明，参考 360 官网的安全防护板块

2. **骨架屏加载态**
   - 首页/产品页加 CSS 骨架屏，避免白屏
   - 参考值得推 PWA 的 `shimmer` 动画

3. **新增"安全体检"页**（admin.html 已有后台，官网可加公开入口）
   - 展示：拦截次数 / 安全评分 / 最近检测
   - 数据来源：后台 stats.feedback + accesslog

### P2 — 中等成本（下版本加）

4. **AI 辅助入口**
   - 在产品页加"AI 安全助手"介绍
   - 用文案说明"AI 驱动的威胁识别"

5. **隐私面板**
   - 新增 privacy.html（已有！确认内容是否充分）
   - 加"我们不追踪什么"可视化列表

6. **功能对比表**
   - 下载页加"绿角犀 vs Chrome vs Edge"功能对比
   - 突出绿角犀的安全优势

### P3 — 高成本（长期规划）

7. **PWA 离线增强**
   - 当前 sw.js 只预缓存静态资源
   - 可加"离线访问上次产品列表"

8. **应用化导航**
   - 移动端底部 tab bar（首页/产品/下载/我的）
   - 参考 Starbucks PWA 卡片式导航

## 禁止事项

- **不要把竞品所有功能都抄过来**（绿角犀走极简路线）
- **不要为了对标竞品引入新框架/构建工具**（保持原生 HTML/JS）
- **不要做"竞品有所以我们也要有"的功能**（必须符合绿角犀定位）
- **不要写空泛的"应该更好"**（必须给具体可执行的改动建议）
- **不要假数据**（下载计数/用户数/评分必须真实）

## 常见坑速查

| 现象 | 根因 | 检查方法 |
|------|------|---------|
| 功能加了但没人用 | 没考虑绿角犀目标用户是谁 | 加功能前先问："这解决绿角犀用户的什么痛点？" |
| 竞品功能看起来酷但实现成本极高 | 没评估落地难度 | 用 Skill 里的"落地难度"列先排优先级 |
| 功能加了破坏极简体验 | 忽略了绿角犀"极简"红线 | 回到 AGENTS.md 第 5 条：禁止引入新框架 |
